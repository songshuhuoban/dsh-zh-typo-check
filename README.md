# 中文检查

在 DSH 输入框里标出中文错别字和半角标点，鼠标指到字上就能改。

---

## 引导

### 1. 安装

**设置 → 插件 → 安装**，填入包名，回车：

```
dsh-zh-typo-check
```

装好后刷新页面即可。**不需要下载任何东西**——规则检查开箱就有。

> 若安装过程提示允许 onnxruntime-node 的构建脚本，请允许：模型的本地推理依赖它。
>
> 需要 DSH **0.2.1-rc.2 或更新版本**：配置持久化用的是 DSH 的插件配置（Config）机制，旧版本没有这个接口。

### 2. 装上模型

规则只能抓它见过的错。要抓「读着不对劲」这类语义错，需要一个本地模型：

**设置 → 插件 → 中文检查 → 下载模型**

- 约 **103 MB**，自动选线路（国内走镜像，连不上走官方）
- 装好后停手约 0.4 秒，模型结果会补到同一份下划线里
- **不装也能用**，只是少了语义这一层

模型只在这台机器上跑，输入的文字不会上传。

### 3. 开始用

1. 在输入框里打一句话
2. 写错的字下面会出现**橙色波浪线**
3. 鼠标**指到那个字上**（不用对准波浪线），弹出气泡：

   ```
   还 → 话
          [忽略]  [替换]
   ```

   **替换**直接改掉；**忽略**这一处不再提示，且会记住上下文，不放过别处的同一个字。

下划线不挡文字，点进段落放光标、选中、打字都照常。

**实验功能**：打开「整句通畅度」后，没有具体错字但整句话读起来别扭时，整句会画一条**蓝色虚线**，鼠标指到那句话上提示「可能不通畅」。它只提示、不替换，因为给不出该改成什么。默认关闭，建议先试几天再决定留不留。

## 配置

都在 **设置 → 插件 → 中文检查**：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 启用检查 | 开 | 关掉后输入框完全不受影响 |
| 检查半角标点 | 开 | 是否标出 `, ? ;` 这类半角标点 |
| 使用模型 | 开 | 关掉只跑规则，仍然立刻响应 |
| 模型灵敏度 | 标准 | 保守少报、激进多报 |
| 整句通畅度（实验） | 关 | 没有具体错字、但整句读起来别扭时，整句下画**蓝色虚线**并提示「可能不通畅」 |
| 下载来源 | 自动 | 自动 / 国内镜像 / 官方 / 自定义地址 |

**配置会持久保留**：改动立即生效，同时写进 DSH profile 的 `cordis.patch.yml`（和模型文件同一个 profile 目录）。重启 DSH、升级插件都不会丢。旧版本存在浏览器里的设置，只要当前页面还读得到（同一次运行内热更、或固定端口部署），会在接上 Host 时一次性迁移过去；桌面版重启会换本地端口，旧 origin 的缓存已经读不到，这部分迁移不了。自定义下载地址是输入框，失焦或按回车时保存；保存失败会在卡片里提示原因，并保留你填的内容。

模型卡片上有一行 **上次模型检查**，能看出模型到底跑没跑、命中几处、耗时多少——模型不生效时先看这一行。

下载失败就把「下载来源」改成「国内镜像」或「官方」再试。用内网镜像的话选「自定义」，填一个基址即可（会拼成 `<基址>/onnx/model_quantized.onnx` 和 `<基址>/tokenizer.json`）。无论哪个来源，下载后都会校验 SHA-256。

## 卸载

**设置 → 插件 → 中文检查 → 卸载**。

想省磁盘的话，先在这页点「删除」清掉模型文件。
