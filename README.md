# 中文检查

在 DSH 输入框中检查中文错字、半角标点，以及中文、英文和混排的整句异常。输入内容在本机处理。

## 安装与首次使用

1. 在 **设置 → 插件 → 添加插件** 输入 `dsh-zh-typo-check`（当前版本 **0.3.0**）。需要 DSH **0.2.1-rc.2 或更新版本**。
2. 若安装提示依赖脚本被拦截，允许 **onnxruntime-node** 的安装脚本并重试。安装完成后点 **立即启用**，重启 DSH。
3. 打开 **设置 → 插件 → 中文检查**。规则检查已经可用；在「整句检查」卡片点 **下载整句模型**，约 **27 MB**，显示「已就绪 · 本地运行」后生效。
4. 在输入框输入文字，停手约 0.4 秒。错字显示橙色波浪线；整句异常显示蓝色虚线。设置页的「最近检查」分别显示错字和整句结果。

两种模型独立下载，也可以只安装整句模型：

| 功能 | 下载 | 提示方式 |
| --- | --- | --- |
| 规则检查 | 无 | 成语误字、部分易错搭配与半角标点 |
| 整句检查 | 约 27 MB | 中文、英文、混排的异常提示；只提示，不改写 |
| 中文错字增强 | 可选，约 104 MB | 补充单字替换建议 |

整句模型与词表合计约 **27.44 MB**；原生推理运行时由 npm 依赖另行安装，不计入模型体积。

## 提示与替换

鼠标指向标记文字即可打开气泡。具体错字有「替换」「忽略」；替换前由用户选择，忽略会结合上下文记住这一处。

整句异常气泡显示「整句意思可能不连贯」。它不会生成或自动替换整句话。模型仍可能误报、漏报，短语、姓名、口语和依赖上下文的输入尤其如此。

整句模型会读取完整输入。任一分词器超过 **128 token** 时显示「超出长度，未检查」，不会只判断截断后的前半段；超过 500 字的输入也跳过模型层，规则继续工作。加载失败或尚未安装模型显示「未就绪」，不表示文本正常。

## 设置与下载恢复

| 设置 | 新安装默认值 | 作用 |
| --- | --- | --- |
| 启用检查 | 开 | 总开关 |
| 整句检查 | 开 | 下载整句模型后生效 |
| 检查半角标点 | 开 | 标出中文语境中的半角标点 |
| 中文错字增强 | 开 | 下载可选错字模型后生效 |
| 错字灵敏度 | 标准 | 仅影响单字建议；不改变整句阈值 |
| 下载来源 | 自动 | 错字模型的自动／国内镜像／官方线路；整句模型默认从 GitHub 下载 |

配置写入当前 DSH profile 的 `cordis.patch.yml`，重启和升级后保留。**旧版已经关闭的整句开关会保持关闭**，升级后需自行打开。

下载过程中可以取消。失败原因会留在卡片中，点击「重试下载」；下载完成后校验大小及 SHA-256。整句模型失败会清理临时文件，重试从头下载。

使用内网镜像时，「下载来源」选 **自定义**，填 HTTP(S) 基址。该地址会同时用于两种模型，文件布局为：

```text
<基址>/semantic-r13-int8.onnx        # 整句模型
<基址>/onnx/model_quantized.onnx     # 可选错字模型
<基址>/tokenizer.json               # 可选错字模型分词配置
```

「运行时不可用」时重新安装插件，并允许 `onnxruntime-node` 的安装脚本，然后重启 DSH。没有模型时，规则与输入框仍可使用。下载联网；日常检查不调用 Jev 或其他云端模型。

## 中英混排与代码

中文错字和标点规则会保护英文词、URL、路径、代码、`.env`、IP 与版本号；混排中的中文错字仍检查。整句模型同时支持中文、英文和混排，不会因为出现英文字母而跳过。

## 升级与卸载

DSH 0.2.2-rc.1 的「更新」按钮可能卡在移除旧版阶段。**已经卡住时，先保存草稿并完全退出 DSH，再通过官方 CLI 离线升级、恢复启用记录**；可使用已验证的[恢复脚本与步骤](https://github.com/songshuhuoban/dsh-zh-typo-check/blob/main/docs/升级卡死恢复.md)。仅刷新页面不会结束宿主事务。不要向运行中的宿主反复热装本地 `file:` 压缩包。

配置与已下载模型会保留。卸载前若要释放空间，分别删除两张卡片的模型，再卸载插件；卸载本身不会自动删除模型与配置。完全清理配置时，删除当前 profile 的 `cordis.patch.yml` 中 `id: zh-typo-check` 对应条目。

插件代码采用 MIT；整句模型与词表的来源、许可和限制见 [MODEL-R13.md](MODEL-R13.md) 与 [NOTICE](NOTICE)。开发和评估见 [CONTRIBUTING.md](https://github.com/songshuhuoban/dsh-zh-typo-check/blob/main/CONTRIBUTING.md)。
