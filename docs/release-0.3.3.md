# 0.3.3 发布记录

2026-11-10，R13 整句模型国内优先自动下载已正式发布到 npm，默认 `latest=0.3.3`。

## 行为

默认「自动（国内优先）」先从魔搭固定版本 `r13-261110` 下载。连接 8 秒未响应、连续 15 秒无进展、HTTP 错误或大小/哈希校验失败时，清理半成品并转 GitHub；持续有进展不受总耗时限制。取消/卸载不触发切换。无需查询用户地理位置。

可手动选择魔搭、GitHub 或自定义，手动来源只访问所选地址。已有明确来源和自定义地址保留；缺少整句来源字段的旧配置默认自动。原 R13 权重、词表、阈值和 ONNX Runtime 1.30.0 不变，已下载模型无需重下。镜像与兼容旧版配置见 [R13 国内镜像](R13-国内镜像.md)。
