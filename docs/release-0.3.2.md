# 0.3.2 正式发布

2026-11-10，用户明确要求将检测一致性和配置表单修复发布到 npm。正式默认版本已更新为 **dsh-zh-typo-check@0.3.2**。

## 变更

整句异常提示不再被局部建议压制。整句异常时暂停不可靠的 MLM 单字猜测，保留确定性规则；连贯句中的错字仍可替换。两套模型分别管理开关、状态、删除和下载来源，迁移旧共享地址，清理重复说明并修复窄屏换行。状态获取失败后限次重试，仍失败时提供刷新；输入框失焦保存，失败保留草稿。

模型、阈值、依赖及本地处理方式沿用原方案，0.3.1 的原生推理子进程隔离继续保留。完整功能及界面验收见[检测一致性记录](checker-consistency-0.3.2.md)。

正式验收实例为本机 `http://127.0.0.1:60364/`，与用户桌面 profile 分离。没有在本轮发布中执行用户桌面升级。

本机测试时，仅输入包名的安装曾选到 0.3.0，因此即时安装或升级请明确指定 **dsh-zh-typo-check@0.3.2**。验收工具增加了实际安装版本断言，避免将旧版当作新版本验证；未修改用户的安装安全设置。
