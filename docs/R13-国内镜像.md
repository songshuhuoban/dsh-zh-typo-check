## 在插件中使用

使用 `dsh-zh-typo-check@0.3.2` 或更新版本，打开 **整句检查 → 下载设置 → 自定义**，地址填：

```text
https://modelscope.cn/models/SimoneWang/dsh-input-anomaly-r13-int8/resolve/r13-261110
```

未安装模型时点击下载。插件会下载 `semantic-r13-int8.onnx` 并核对大小和 SHA-256。已下载的相同 R13 模型可继续使用；两套词表随插件分发。这个来源用于整句模型，错字增强卡片的来源单独设置。

模型文件[直链](https://modelscope.cn/models/SimoneWang/dsh-input-anomaly-r13-int8/resolve/r13-261110/semantic-r13-int8.onnx)。同一权重的 [GitHub 固定发布](https://github.com/songshuhuoban/dsh-zh-typo-check/releases/tag/r13-model-20261110)继续提供。

## 发布内容与复现

仓库包含 INT8 ONNX、中文/英文词表、Apache-2.0 许可、NOTICE、模型说明、推理配置和哈希清单。使用源码脚本可从已经公开的冻结制品重新准备目录：

```powershell
node tools/prepare-r13-mirror.mjs <输出目录> <已发布模型文件>
```

脚本只接受固定模型和词表哈希，拒绝覆盖不同文件，也拒绝混有未计划文件的输出目录。原始训练语料、输入法采集记录和随机数档案不包含在发布目录中。
