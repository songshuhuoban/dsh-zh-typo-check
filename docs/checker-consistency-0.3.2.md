# 0.3.2 候选版：检测一致性与配置表单

整句模型已将“这个方案有点危显是的管理开始地灵龛你看了”判为异常，但旧客户端仅在没有局部建议时显示蓝色提示。桌面装有错字模型，网页测试实例没有，因此同一个整句判定呈现出不同结果。

本次让整句提示独立显示。整句异常时暂停 MLM 单字猜测，保留确定性规则；正常句子仍提供单字替换。局部提示优先响应鼠标，多行蓝线逐行绘制，行高变化会重新定位。

表单改成全局开关与两张独立模型卡。各卡合并开关、状态、体积和删除操作，下载来源放进各自的折叠设置。104 MB 错字模型仍作为可选增强。删除重复说明和重复标题，来源下拉框及窄屏单列布局避免按钮被拆行。旧共享自定义地址迁移后分别持久化；输入框失焦保存，失败保留草稿并短暂提示。

状态轮询遇到临时故障后按 1、2、4 秒重试，仍失败时保留可访问的刷新按钮，避免永久显示旧下载进度。

## 已识别的运行时限制

测试用 Python HTTP/1.0 文件服务器会在 DSH 所带 Node **24.21.0** 的 undici `Parser.finish` 触发 `assert(!this.paused)`，模型子进程退出码为 1；独立 IPC 探针复现了同一堆栈。换用 HTTP/1.1 后完整下载及校验通过。此次补齐客户端状态恢复；HTTP/1.0 下载传输兼容性仍须另行处理，不能将它宣称为已修复。
